# DLs-Classroom

Digital gamified classroom software. Used to gamify a classroom as way of keeping student interested and focused. 

## Teck Stack

Database: Postgres
Backend: C#
Frontend:

- Typescript
- Photino + Vite

## Development

### Frontend

To have frontend hot reload run npm run dev from the frontend directory. Additionally, make sure to run npm install before making changes to App.tsx.
